🦅 Osprey

SBOM Security Auditing & CISA KEV Vulnerability Detection

Quick Install

Run this command in your terminal:

curl -fsSL https://purplelotus.space/install-osprey.sh | bash

What is Osprey?

Osprey (CLI command: cra) is a powerful security tool that helps you identify actively exploited vulnerabilities in your software dependencies by cross-checking against the CISA Known Exploited Vulnerabilities (KEV) catalog.

Features

Multi-Ecosystem

Supports 6 package ecosystems

KEV Detection

Cross-checks against CISA KEV

Version Intelligence

Uses OSV.dev for accuracy

Remote Auditing

Audit GitHub repos directly

Supported Ecosystems

JavaScript/TypeScript (npm)
Python (PyPI)
Java (Maven)
Rust (Crates.io)
.NET (NuGet)
Ruby (RubyGems)

Quick Start

After installation, try these commands:

cra --path . # Audit current project
cra --url owner/repo # Audit GitHub repository
cra --help # Show all options

Prerequisites

  • Node.js 18 or higher
  • npm
  • git

Manual Installation

git clone https://github.com/purplelotus/osprey.git
cd osprey
npm install
npm run build
npm link
